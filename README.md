# VR TEST

created for hackclub terra


## INSTALLATION

make sure you have FFMPEG and YT-DLP installed on path if u want the TVS to work

download and run the executeable corrosponding to your OS from the releases page

the windows build is untested.


## SET UP

This setup has only been able to be tested on a Quest-3s Using steam link. it should hypothetically work with other setups but i cannot make garunetees. It has been tested on multiple computers but both of them ran linux.


Install Steam Link on your headset

install steam VR on your computer

set Steam VR as your open xr default in steam link. 

launch the executebale 

it should just boot


## FEATURES
TVS that allow you to watch both youtube videos and files downloaded to your pc

multiple fun cool areas to explore

a few random items you can pickup and mess with

mirrors you can look at yourself in (ur boring to look at)
